**10. 应用描述**
```
同时开着一堆应用，屏幕总是很乱？DeskTidy 住在菜单栏里，一键把此刻用不到的应用收起来，只留下你正在用的。

· 一键清理：一个快捷键（可自定义），把用不到的应用收起（隐藏，不是关闭），它们在后台照常运行。
· 一键恢复：把刚才收起的应用全部放回来。
· 工作场景：为写代码、做设计、开会等不同场景设好要保留的应用，切换场景就能一键清理。
· 番茄钟：专注计时，到点提醒休息。

DeskTidy 不联网，不收集任何数据。

系统要求：macOS 13 或更高版本。
```

**32. 审核操作说明**
```
无需账号、网络或特殊硬件，需要 macOS 13 或更高版本。App 不申请任何系统权限。

1. 启动后，DeskTidy 只显示在菜单栏（三颗星图标），程序坞中没有图标。首次启动会弹出欢迎窗口。
2. 点击菜单栏图标打开面板，也可以按 ⌥⌘J。
3. 先打开几个其他应用，再点击面板中的"一键清理"（默认快捷键 ⌥⌘K）。除当前在用的应用外，其余应用会被隐藏（不会关闭），屏幕中央提示"已收起 N 个应用"。
4. 点击"一键恢复"，刚才隐藏的应用全部恢复显示。
5. 工作场景：在面板中选择一个场景（如"AI 工作"），展开"正在运行"，勾选要保留的应用，再点"一键清理"，勾选的应用会被保留。
6. 番茄钟：点击"开始专注"，屏幕角落出现计时小时钟；到点后进入休息界面，可点"跳过休息"或按 esc 退出。
7. 设置：点击面板底部"设置…"或按 ⌘,，可修改场景、外观、提示音、专注时长和快捷键。
```
